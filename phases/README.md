# Phases

The project follows the nine default phases of the clean-code standards. Each folder holds the phase's goal, scope, tasks, acceptance criteria, verification and status. A phase is marked done only with the checks that prove it.

| --- | --- | --- | --- |

| 02 Foundation | Done | Phase 01 | [phase-02-foundation](phase-02-foundation/README.md) |
| 03 Data | Done | Phase 02 | [phase-03-data](phase-03-data/README.md) |
| 04 Server logic | Done | Phase 03 | [phase-04-server-logic](phase-04-server-logic/README.md) |
| 05 Client foundation | Done | Phase 04 | [phase-05-client-foundation](phase-05-client-foundation/README.md) |
| 06 Client screens | In progress | Phase 05 | [phase-06-client-screens](phase-06-client-screens/README.md) |
| 07 Mobile | In progress | Phase 04 | [phase-07-mobile](phase-07-mobile/README.md) |
| 08 Quality | Done | Phase 04 (covers the web and mobile code written so far) | [phase-08-quality](phase-08-quality/README.md) |
| 09 Documentation and release | In progress | Phase 08 | [phase-09-documentation-release](phase-09-documentation-release/README.md) |

Work done before the phase plan existed was committed straight to the main branches; from the 2026-11-05 review on, each fix has its own branch and pull request.
